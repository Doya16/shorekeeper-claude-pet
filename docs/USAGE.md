# Claude 版使用说明

## 连接

先打开桌宠，右键 → 外观、声音与迁移 → 连接 Claude。

勾选“连接 Claude Code 任务事件与额度状态栏”，然后重新打开 Code 会话。需要 Claude Code 2.1.295 或更新版本。桌面普通聊天与 Cowork 尚未适配。

连接设置会保留其他工具的 hooks。已存在自定义状态栏时会保留，不接管额度显示。修改前的 Claude 设置保存在 Claude 数据目录的 `shorekeeper-backups` 中。取消勾选只移除本桌宠添加的连接。

数据目录通常留空；使用自定义 Claude 配置目录时，先断开连接，再选择该目录并重新连接。网络登录、账号授权与目录信任仍由 Claude 自己处理。

## 动作与声音

右键 → 交互工作室，选择动作后设置 GIF、循环、速度与停留时间。一个动作可以放多条音频，每条音频单独填写字幕。

气泡内容选择“自定义音频+字幕”，就会展示本次抽中的语音对应台词。没有音频时不弹出额外的默认台词。也可以选择其他气泡模式。

思考动作建议使用“每轮任务一次”。查阅与编辑回到思考时不会反复播报。待机动作可选择“每次进入”“每次启动一次”或“偶尔播放”。缺失音频不会阻止 GIF 或其他提醒。

多个会话各自完成时都会进入提醒队列。任务事件暂时无法读取时显示连接状态，不把沉默直接判定为完成。

## 额度

5 小时与每周额度独立展示。额度为 Claude Code 最近提供的数据，右键刷新只重新读取本机记录，不会额外发送模型请求。

悬停可查看重置时间、最近同步时间，以及接口提供的会话上下文和费用估算。上下文不是套餐额度，费用估算也不是余额。额外用量余额暂不显示数值。

接口没有提供额度时显示“待同步”；有自定义状态栏、API 账号、尚未收到模型响应等情况都可能没有数据。桌面 Code 的用量同步仍需真实环境确认。

## 保存与携带

所有设置自动保存。移动之前可导出“Windows 便携完整包”，包含程序、素材和配置。完整解压到另一台 Windows 电脑后运行，再完成 Claude 登录。

只想传递素材与个人设置，可导出“配置与素材包”。它不包含程序，也不携带 Claude 的账户、对话或历史用量数据。

升级时把新程序解压到新目录，然后导入自己的配置与素材 ZIP。保留旧目录，确认新版本正常后再自行清理。

## 当前预览范围

保留了表情、声音、字幕、交互、自定义字号、尺寸预览与拖动、配置迁移、启动联动和版本提醒。连接层已完成软件实现，真实 Claude Code 登录、真实额度以及桌面 Code 联调留待后续；普通桌面聊天与 Cowork 不标记为已支持。
