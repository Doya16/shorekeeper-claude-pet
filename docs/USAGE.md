# Claude 版使用说明

## 连接

右键菜单只保留常用操作，所有设置集中在 **右键 → 设置…** 这一个窗口里（左侧切换页面）。连接相关的设置在 **Claude 额度与提醒** 页。

**Claude 桌面版的 Code 会话不需要任何设置。** 任务状态读取本机会话记录，额度读取桌面版自己写在本机的用量记录。

**只用终端 Claude Code** 时，勾选“终端 Claude Code：安装任务事件与额度状态栏（可选）”，然后重新打开终端会话。需要 Claude Code 2.1.295 或更新版本。桌面普通聊天与 Cowork 尚未适配。

连接设置会保留其他工具的 hooks。已存在自定义状态栏时会保留，不接管额度显示。修改前的 Claude 设置保存在 Claude 数据目录的 `shorekeeper-backups` 中。取消勾选只移除本桌宠添加的连接。

数据目录通常留空；使用自定义 Claude 配置目录时，先断开连接，再选择该目录并重新连接。网络登录、账号授权与目录信任仍由 Claude 自己处理。

## 需求状态与后台任务

桌宠底部第一栏 **“需求”** 只跟踪你亲自发送的最近一条消息：

- **处理中 · N 分钟**（蓝色）：Claude 还在处理你的需求。
- **已完成 · 14:02**（绿色）：这一轮已经回复完毕。
- **出错了 · 14:02**（橙色）：这一轮异常结束，回到 Claude 查看。

悬停桌宠或打开右键菜单，可以看到会话名称、用时，以及有几个后台任务正在运行。

后台命令或子任务完成后的回报、定时任务、Monitor 事件，以及由其他会话新建的会话，都是 Claude 自己发起的轮次。“Claude 自己发起的轮次”可以选择：

- **静音（推荐，默认）**：不播语音、不切换动画、不弹完成提醒。
- **仅动画**：切换表情，但不说话、不弹完成提醒。
- **完整提醒**：与你亲自发出的需求一样播报开始与完成（旧版行为）。

如果后台结果在你的需求还没结束时送达，它会算作这条需求的一部分，不会重新开始计时。

Claude 回复时如果还留着它为这条需求启动、仍在运行的后台命令，需求条显示 **处理中 · 等后台任务**；结果回来、Claude 处理完之后才播报“完成”。开发服务器、文件监视这类常驻进程不计入等待；等待超过 30 分钟没有动静则静默收尾。

多个项目同时进行时，需求条显示 **N 个处理中**；其中一个完成单独提醒，不打断另一个的动画，自动跟随会停在正在处理的项目上。

## 右键菜单与常规设置

右键菜单：摸摸头、递一杯奶茶、**Claude 与额度**（鼠标移上去展开：打开 Claude、打开官方用量页面、刷新额度）、**设置…**、暂时收起、退出。托盘菜单：显示／隐藏、设置…、退出。

**设置… → 常规** 中可以切换表情风格、保持置顶，以及 **精简气泡**。精简气泡只影响文字气泡，不影响语音：开启后，思考、查阅、编辑、执行、待机等进度状态不再弹出默认台词；完成、出错、等你回应、摸头等互动，以及设为“自定义文字”或“音频+字幕”的气泡照常显示。要关掉声音请到 **声音** 页。

## 动作与声音

右键 → 设置… → **交互工作室**，选择动作后设置 GIF、循环、速度与停留时间。一个动作可以放多条音频，每条音频单独填写字幕。

气泡内容选择“自定义音频+字幕”，就会展示本次抽中的语音对应台词。没有音频时不弹出额外的默认台词。也可以选择其他气泡模式。自定义气泡文字中可以使用 `{request}` 显示需求状态。

思考动作建议使用“每轮任务一次”。查阅与编辑回到思考时不会反复播报。待机动作可选择“每次进入”“每次启动一次”或“偶尔播放”。缺失音频不会阻止 GIF 或其他提醒。

多个会话各自完成需求时都会进入提醒队列。任务事件暂时无法读取时显示连接状态，不把沉默直接判定为完成。

## 底部状态条

右键 → 设置… → **底部状态条**。页面顶部的预览与桌宠底部完全一致，所有改动立即生效：

- **需求完成条**：可以关闭。
- **额度框**：5 小时、每周、Fable 每周，以及其他模型专属或网关支出额度合并在同一个框里，每项可以单独勾选是否显示。勾选的额度没有数据时显示“待同步”。
- **显示方式**：条形（每项下方一条余量条）或圆环（环中显示剩余百分比）。余量低于 20% 时变为橙色。
- 勾选“用示例数据预览”可以在没有真实数据时查看效果，不影响桌宠。

Fable 额度只有在 Claude 返回 Fable 专属窗口（例如状态栏的 `seven_day_fable`）时才有数值；目前桌面版用量记录与官方状态栏都只提供 5 小时和每周。

## 额度

5 小时与每周额度独立展示，不能相加。额度有两个本机来源，两个都有数据时显示较新的一个：

- **Claude 桌面版用量记录**：桌面版打开期间约每 15 分钟采样一次，自动读取。桌面版 Code 会话不执行状态栏命令，所以这是使用桌面版时唯一的本机来源；手动刷新会提示采样时间和下次更新时间。只有已用百分比，没有重置时间；超过 20 分钟未更新时显示 `*`。
- **Claude Code 状态栏**：终端会话勾选连接后可用，带重置时间；超过 5 分钟未更新时显示 `*`。

“Claude 额度与提醒”页会显示每个来源的状态和最近同步时间。右键 → Claude 与额度 → 刷新额度，只重新读取本机记录，不读取账号凭据，也不会额外发送模型请求。

悬停可查看重置时间、最近同步时间与来源。上下文不是套餐额度，费用估算也不是余额。额外用量余额暂不显示数值。两个来源都没有数据时显示“待同步”。

## 保存与携带

所有设置自动保存。移动之前可导出“Windows 便携完整包”，包含程序、素材和配置。完整解压到另一台 Windows 电脑后运行，再完成 Claude 登录。

只想传递素材与个人设置，可导出“配置与素材包”。它不包含程序，也不携带 Claude 的账户、对话或历史用量数据。

升级时把新程序解压到新目录，然后导入自己的配置与素材 ZIP。保留旧目录，确认新版本正常后再自行清理。

## 当前预览范围

保留了表情、声音、字幕、交互、自定义字号、尺寸预览与拖动、配置迁移、启动联动和版本提醒。桌面版 Code 会话的任务状态与额度已在真实环境读取；终端状态栏额度与普通桌面聊天、Cowork 尚未实机联调。
