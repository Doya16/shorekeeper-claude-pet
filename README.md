# 守岸人 Claude 桌宠

让守岸人陪你使用 Claude Code。选择自己喜欢的表情、语音与字幕，把思考、查阅、编辑和任务完成变成看得见的陪伴。

**Windows 10/11 x64 · v0.1.0 预览版**

本版先适配 **Claude Code 终端**与**Claude 桌面版中的 Code 会话**。普通聊天和 Cowork 留待后续适配。真实账号的任务事件与额度尚待联调，当前不作为已验证的正式版发布。

## 开始使用

1. 完整解压 `Shorekeeper-Claude-Windows-v0.1.0-preview.zip` 到可写目录。
2. 双击 **守岸人Claude桌宠启动.exe**。不需要另装 Python。
3. 右键桌宠 → **外观、声音与迁移 → 连接 Claude**。
4. 准备联调时，勾选 **连接 Claude Code 任务事件与额度状态栏**，然后重新打开 Claude Code 会话。
5. 在 Claude Code 登录自己的账号，选择自己的工作目录。

建议 Claude Code **2.1.295 或更高版本**。终端与桌面客户端的登录可能相互独立。首次启动默认不修改 Claude 连接设置，不启用开机联动。

## 你可以调整什么

| 想做的事 | 在哪里设置 |
| --- | --- |
| 每个动作使用不同 GIF | 右键 → 交互工作室 → GIF 素材 |
| 添加自己的素材 | GIF 素材 → 打开素材目录，放入文件后刷新 |
| 循环、单次播放、播放速度、结束后停留 | 交互工作室 → 播放设置 |
| 一个动作随机播放多条语音，每条配不同字幕 | 交互工作室 → 语音与字幕 |
| 只在一轮任务开始时播报一次 | 思考动作 → 语音触发频率 → 每轮任务一次 |
| 待机语音每次、每次启动一次或偶尔播放 | 待机动作 → 语音触发频率 |
| 只显示语音配对字幕 | 气泡内容 → 自定义音频+字幕 |
| 字体、字号、音量 | 外观、声音与迁移 |
| 桌宠大小 | 右键 → 调整大小，或 Ctrl + 滚轮 |
| 气泡和底部额度大小 | 拖动左右边缘，或在大小设置中实时预览 |
| 随 Claude 启动 | 外观、声音与迁移 → 连接 Claude |
| 保存或搬到新电脑 | 外观、声音与迁移 → 保存与迁移 |

双击与拖拽也可以绑定表情和语音。声音播放期间切换 GIF 不会截断当前句子；多个任务完成时，各自的提醒依次展示。

GIF 列表支持 **GIF / WebP / PNG / JPG / JPEG**。语音支持 **WAV / MP3 / OGG / FLAC / M4A / AAC**，字体支持 **TTF / OTF / TTC**。音频路径留空不影响其他功能。

## Claude 额度怎么看

桌宠分别显示可获取的额度：

- **5 小时剩余**：当前短周期可用比例。
- **每周剩余**：当前周周期可用比例。
- 其他模型专属或网关支出窗口，仅在 Claude 返回对应数据时显示。

每项分别计算，不能相加或取平均。一个窗口用完，并不代表另一个窗口也归零。

没有返回的数据显示 **额度：待同步**。到期窗口等待下一次同步，不会自行假定恢复到 100%。超过 5 分钟未更新时显示 `*`，鼠标悬停可看最近同步时间。

当前会话上下文、会话费用估算、套餐额度与额外余额是不同概念。上下文与费用估算仅放在悬停说明中；**额外用量余额暂未获取**。右键 → **打开官方用量页面** 可查看账号实际信息。

额度数据来自 [Claude Code 官方状态栏](https://code.claude.com/docs/en/statusline)。订阅计划或网关可能提供不同字段，普通 API 账户未必有套餐百分比；桌面 Code 是否执行状态栏用量同步尚待实机确认。若已使用自定义状态栏，连接时会保留它，此时桌宠只接入任务事件。

## 保存、迁移与升级

修改自动保存在 `settings.json`。在 **保存与迁移** 页面：

- **立即保存全部配置**：保存当前设置。
- **配置快照（JSON）**：只保存配置文字。
- **配置与素材包（ZIP）**：包含 GIF、气泡文案、配对字幕、音频、字体和设置。
- **Windows 便携完整包（ZIP）**：额外包含运行程序，可直接搬到另一台 Windows 电脑。

新电脑完整解压后运行，再安装并登录自己的 Claude。已开启的连接和启动联动，会在新电脑首次运行桌宠时重新配置。本机连接路径与固定会话会重置；迁移包不包含 Claude 账号凭据、聊天记录或额度缓存。

Codex / DeepSeek 版的配置与素材 ZIP 也可导入 Claude 版；导入后在 **连接 Claude** 页面启用对应连接。

当前预览版尚未发布 GitHub 正式版本。保留了更新提醒功能，正式发布后可启用；不会自动覆盖本地配置。
