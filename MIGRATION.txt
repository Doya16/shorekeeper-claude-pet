守岸人 Claude 桌宠 · v0.1.0 预览版

1. 完整解压 ZIP 到可写目录。
2. 双击“守岸人Claude桌宠启动.exe”，无需安装 Python。
3. 右键 → 外观、声音与迁移 → 连接 Claude。
4. 准备联调时勾选连接，再重新打开 Claude Code 会话。
5. Claude Code 建议 2.1.295 或更新版本。账号登录请在 Claude 内完成。

首次启动使用当前附带的 GIF、语音字幕与外观配置。
默认不安装 Claude 连接、不启用启动联动。
修改自动保存至 settings.json。
随时可在“保存与迁移”导出完整程序、GIF、字体、气泡、字幕与音频。
迁移包不会携带账号凭据、聊天记录或额度缓存。

tools/创建桌面快捷方式.cmd 可创建桌面快捷方式。
程序代码在 shorekeeper_pet，辅助工具在 tools；不要单独移动 exe 或 _internal。

真实账号与额度联调尚未完成。普通聊天与 Cowork 将在后续适配。
升级请使用新目录并导入自己的配置包，不要直接覆盖唯一备份。
